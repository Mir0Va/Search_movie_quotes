# Search_movie_quotes
The dataset of quotes (data.json) from https://github.com/NikhilNamal17/popular-movie-quotes/tree/master

website (may take ~1min to spin-up the server): https://search-movie-quotes.onrender.com/

# .env
the .env file must contain the openai api key:
OPENAI_KEY = {the api key}

# Running locally
to run the app, use the following command in the search_movie_quote folder:

```console
flask --app app.py run
```
